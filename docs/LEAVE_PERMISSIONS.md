# Leave appeals and permissions

Teacher and Class Teacher have a personal appeal workflow in Leave Management:

1. Submit their own leave dates and type. This creates one application and its
   coverage requests from their saved timetable.
2. Track coverage, application status and any rejection reason.
3. Once management has arranged every substitute period, submit their reason to
   send the application for HOD and then Principal review.

They cannot appeal for another person, assign/accept/decline substitutes, review
or reject applications, view other people's leave lists, or edit campus content.
Students retain their existing read-only interface. All users retain the four
existing navigation items.

Management retains coverage assignment and hierarchical review. Existing data,
accounts and applications require no migration. These rules supersede the older
blanket read-only description for teaching staff in the integration documentation.
